ARSENAL WEBSITE FILES

Extract this ZIP. Upload the eight website files to the main folder of your existing GitHub repository, replacing files with matching names. Include both PNG images. Commit the upload, wait for GitHub Pages to publish, then refresh the website.

arsenal.html is the new standalone page. Arsenal is added to the main menu through index.html. reference.css supplies shared table and page styling. economy.js is included because this index.html also references the latest Economy type-filter update.

Keep all your other existing website files, especially site-config.js, mobile.css, mobile.js, season.js, icons.svg, style.css, characters.css, hero artwork, catalog data and resource-art folder. This is an update package, not a complete replacement website.

No Apps Script changes are needed for Arsenal. It reads the public Arsenal reference sheet and includes a saved fallback. Weapons and Armor are separated, with equipment type and attribute dropdowns, search and expandable pictures.
