3. Upload the 18 website files in this folder to the repository's main folder, replacing the same-named files. Include both new PNG images and ledger-art.js.
4. Commit the upload, wait for GitHub Pages to publish, and refresh the website with Ctrl+Shift+R.

Keep your existing site-config.js, catalog.js, economy-data.js, resource-art.js, resource-art folder, hero artwork, and other files. No Google Apps Script or spreadsheet changes are required. This is an update package for the existing website.
