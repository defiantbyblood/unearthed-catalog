CHARACTER MASTER LIST
Your shared Google Sheets registry already exists:
https://docs.google.com/spreadsheets/d/1cphSQdDRBjMO3w_mv3F4n2SW2faqJ0wqgHvJeIpodjw/edit

The separate Unearthed-Google-Character-Connection.zip contains the Google Apps Script submission code and START-HERE.md instructions. Install it in Google Apps Script, authorize and deploy it, then paste its /exec URL into characterRegistrationUrl in site-config.js and upload that file. The submission connection is not live until that setup is done.

Everyday workflow after setup: copy and complete the master character sheet; share the player copy as Anyone with the link - Viewer; use Character Sheets > Add New Character Sheet on the website; preview and submit with your approved Google account. It adds the character to the shared Google Sheets master list. The website reads that list automatically. Each character has a themed player link and a link to the original Google Sheet.

No moderator account settings or passwords belong in the public GitHub files. Keep the Apps Script project and its moderator settings in Google. Do not change the registry column headings. Google can cache public spreadsheet downloads for a few minutes.
